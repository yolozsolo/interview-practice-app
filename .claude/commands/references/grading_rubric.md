# Grading Rubric

## Correctness

Does the implementation solve the stated task?

## Code quality

Is the code readable, typed, simple, and maintainable?

## Edge cases

Does the answer handle nulls, duplicates, malformed inputs, ordering issues, and empty inputs where relevant?

## Spark / Delta reasoning

Does the candidate understand distributed execution, shuffle, joins, partitioning, Delta MERGE, transaction log concepts, schema evolution, and retry-safe design?

## Testing

Are tests meaningful, not just happy-path?

## Production readiness

Does the answer mention observability, idempotency, backfills, data quality, failure handling, and operational concerns?

## Communication

Would this answer sound credible in a senior / lead interview?
